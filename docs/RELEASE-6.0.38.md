# Nuvio Hub 6.0.38 — back to 6.0.36

Released 2 October 2026.

6.0.37 showed "Could not open the interface" on Android with Kodi 22 beta.
6.0.38 is the same code as 6.0.36, with a higher version number so every
device updates back to it on its own (Kodi and the MegaNexus updater only
install a higher version). Nothing in your settings, accounts or collections
changes.

The 6.0.37 features (Kodi 22 RC1, touch rows, Trakt/TMDB collection sources,
Local storage, security notice, phone setup port 8765; see
[RELEASE-6.0.37.md](RELEASE-6.0.37.md)) come back in a later version once
the Android problem is found and fixed.
