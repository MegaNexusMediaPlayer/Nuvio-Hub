# ➡️ MegaNexus has moved

**MegaNexus now lives at [github.com/MegaNexusMediaPlayer/MegaNexus](https://github.com/MegaNexusMediaPlayer/MegaNexus).**
New versions, downloads, the Kodi repository and issues are all there from now on. This old project will be removed soon.

### Already using MegaNexus?

Nothing to do. Your MegaNexus updates by itself to **MegaNexus 7**: it installs the new add-ons (MegaNexus Hub, MegaNexus, MegaNexus Skin, MegaNexus Screensaver), moves your settings, accounts, add-ons and Continue Watching, and removes the old add-ons after one restart. Choose **Yes** when Kodi asks to keep the MegaNexus skin.

Prefer to update by hand? Install **[the update zip](https://github.com/MegaNexusMediaPlayer/Nuvio-Hub/releases/latest)** with Kodi → Add-ons → Install from zip file.

### New installation

Use the new project: **[MegaNexus releases](https://github.com/MegaNexusMediaPlayer/MegaNexus/releases/latest)**, or add `https://meganexusmediaplayer.github.io/MegaNexus/` as a source in Kodi's File manager.
